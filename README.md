# ChatGPT Mocha Wide – UserStyle

A polished **UserStyle for ChatGPT** inspired by the **Catppuccin Mocha** palette.
Designed for long sessions, wide screens, and dark-mode lovers.

## ✨ Features

- **Wide (semi-edge) layout** – removes unnecessary side margins
- **Dark glass cards** for user & assistant messages
- **Darker, cleaner composer** with stronger borders
- **Catppuccin Mocha color palette** (teal + mauve accents)
- **Minimal menus** with border-only hover (no bright fills)
- **Clean bottom UI** (disclaimer hidden)
- **Cross-browser scrollbar styling** (Firefox & Chromium)
- Safe for syntax highlighting and long code blocks

## 🖥️ Supported Browsers

- Firefox / Zen (recommended)
- Chromium-based browsers (Chrome, Edge, Brave, etc.)

> Optimized for **dark mode only**

## 📦 Installation

1. Install a userstyle manager:
   - **Stylus** (recommended)
2. Import the `.user.css` file into Stylus
3. Enable the style on `chatgpt.com`

## 🎨 Customization

All colors and sizes are defined using CSS variables inside `:root`.
You can easily tweak:
- Border intensity
- Accent colors
- Scrollbar size
- Card opacity

## 📝 Notes

- This style targets ChatGPT’s current UI structure (2026).
- Minor selector updates may be required if ChatGPT changes its layout.
